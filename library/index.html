How the Python project works

  • Book: stores a title, author, and private copy count.
  • Library: adds books, combines matching titles, and manages borrowing and returns.
  • JSON: saves and reloads structured book data.
  • CSV: exports book details in rows and columns.
  • Exceptions: help report missing books and unavailable copies.

This webpage demo stores changes in memory while the page is open. It does not change the Python files on GitHub.
