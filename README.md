# Agentic AI Engineering — Python Assignment Solutions

This repository organizes practice solutions for the assignments listed in the GiftAbled Foundation document *Every Assignment So Far* (17 September–15 October 2026).

## Important before submitting
- Read every solution and make sure you can explain it.
- Run the programs yourself and capture any outputs/screenshots your trainer requests.
- Replace example names and data with your own where required.
- Assignment A7 asks for three student objects, with the first using your own name.
- Assignment A8 asks you to show both a failed route and a winning route.
- Assignment A9 / Mini Library System requires `AI_USAGE.md` to be filled in.
- These are learning solutions. Follow your trainer's exact repository structure and naming requirements if they differ.

## Contents
- `A1_first_programs/` — name, greatest of four numbers, ticket price, electricity bill
- `A2_loops_conditionals/` — six compulsory tasks, one selected Part B task (GCD), and written reflection
- `A3_lists_strings/` — lists, marks, vowels, palindrome
- `A4_list_comprehensions/` — pass/fail list comprehension
- `A5a_bank_class/` — private balance, deposit, withdrawal
- `A5b_library_homework/` — Book and Library classes
- `A6_file_handling/` — text, CSV, JSON
- `A7_oop_files_exceptions/` — Student class, persistence, exceptions, written answers
- `A8_missing_fest_trophy/` — text adventure with failed and winning routes
- `A9_mini_library_system/` — Mini Library System with JSON, CSV, text reader, exceptions, and checker

## Run a program
Open a terminal in the relevant folder and run, for example:

```bash
python greatest_of_four.py
```

For A9, go into `A9_mini_library_system/` and run:

```bash
python check.py
```

## Suggested GitHub upload
1. Create a new GitHub repository, e.g. `agentic-ai-python-assignments`.
2. Extract this ZIP file.
3. Open a terminal inside the extracted `agentic_ai_assignments_github` folder.
4. Run:

```bash
git init
git add .
git commit -m "Add Python assignment solutions"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/agentic-ai-python-assignments.git
git push -u origin main
```

Replace `YOUR-USERNAME` and the repository URL with your actual GitHub details. Never share your GitHub password or personal access token in chat.
