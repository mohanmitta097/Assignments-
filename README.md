# Mohan's HTML, CSS and JavaScript webpages

Two starter-guide projects:
- `resume/`: personal resume webpage (`index.html`, `style.css`)
- `library/`: interactive Mini Library webpage (`index.html`, `style.css`, `script.js`)

Open each `index.html` in a browser or use VS Code Live Server.

Before publishing, replace `YOUR-EMAIL@example.com` with an email you are comfortable sharing (or remove it), verify education details, and edit skills/content to match what you can explain.

For GitHub Pages, put the contents of `resume/` at the root of your resume repo and the contents of `library/` at the root of your Library website repo. Go to Settings → Pages, choose branch `main` and folder `/(root)`, then Save. Keep the file name exactly `index.html`.
